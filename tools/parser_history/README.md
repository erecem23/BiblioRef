# Parser evaluation history

Scripts that produced the development, holdout and sweep evaluations of the downstream bibliographic parser (versions 0.2–0.10). They are kept as a record of how each parser version was evaluated and are not maintained.

They read the gold sets in `parser_baseline/` and the prediction CSVs, which contain reference strings extracted from real theses and are not distributed with BiblioRef. Some scripts also read evaluation JSON files that now live in `docs/history/`. Run them from the repository root.
